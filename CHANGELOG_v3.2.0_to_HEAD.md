# Changelog: `v3.2.0` -> `HEAD` (`a909abd`)

- Период: `2025-07-11` (`5540dc9`, tag `v3.2.0`) -> `2026-02-20` (`a909abd`)
- Диапазон: `git diff v3.2.0..HEAD`
- В диапазоне релизные теги: `v4.0.0`, `v4.0.1`, `v4.0.2`, `v4.0.3`, `v4.0.4`
- Масштаб изменений: `91` коммит, `95` файлов, `+9118 / -3202` строк

## Ключевые изменения

1. Перестроен пайплайн сборки конфигурации ядра:
   - добавлен новый модульный билдер `v2/config/builder.go`;
   - переработаны `v2/config/config.go`, `v2/config/parser.go`, `v2/config/outbound.go`.
2. Существенно расширен DNS-стек:
   - добавлен отдельный слой `v2/config/dns.go`;
   - реализованы `fakeip/fake dns`, fallback DNS, отдельные detour-сценарии для DNS.
3. Улучшена поддержка WARP/WireGuard:
   - расширена генерация/патчинг WARP-эндпоинтов в `v2/config/warp.go`;
   - добавлены сценарии `proxy_over_warp` и `warp_over_proxy`, а также шум (noise) для WARP.
4. Переработана логика выбора маршрута и балансировки:
   - в `v2/config/builder.go` добавлен balancer-подход (`lowest-delay`, `round-robin`);
   - улучшено поведение selector/URL test и detour-маршрутизация.
5. Расширены входящие интерфейсы VPN-трафика:
   - поддержка `tun`, `tproxy`, `redirect`, `direct` в едином контуре сборки;
   - обновлены опции `InboundOptions` (в т.ч. `redirect-port`, `direct-port`).
6. Улучшен runtime API ядра (gRPC/proto):
   - обновлены `v2/hcore/hcore.proto`, `v2/hcore/hcore_service.proto`;
   - добавлены/обновлены методы и структуры для мониторинга, управления и закрытия сервиса.
7. Добавлены возможности управления жизненным циклом на мобилках:
   - `Pause/Wake` в `v2/hcore/pause.go`;
   - экспортировано в mobile-слое (`platform/mobile/mobile.go`).
8. Добавлен режим прямого запуска sing-box через CLI:
   - новый `srun` в `cmd/cmd_sing_run.go` (запуск без полного Hiddify orchestration).
9. Добавлены и обновлены артефакты упаковки/дистрибуции:
   - systemd/openwrt-конфиги в `release/config/*`;
   - обновления сборки и дистрибуции в `.github/workflows/build.yml`.
